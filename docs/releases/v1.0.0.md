# FloatingBar v1.0.0

The first stable FloatingBar release: answer AI permission requests and manage everyday tasks from a floating bar on Windows.

### Highlights

- Review supported Claude and FloatingBar-owned Codex permission requests, then choose **Allow / Deny** without switching windows.
- Chat with Claude or Codex, browse conversations, and receive replies in the AI panel. Sending from an existing Codex conversation creates a fork to preserve the original.
- Control Discord voice: view members, adjust individual volume, mute, deafen, disconnect, and pin the panel or collapse it to avatars.
- Manage local to-dos, today's Google Calendar agenda, music playback, notifications, and header shortcuts.
- Drag the header to reposition the bar, swipe the body to change pages, and expand upward near the bottom of the screen.
- New in-app connection guides for Google Calendar, Discord, and ChatGPT / Codex, plus an illustrated Indonesian guide linked from the README.
- Keep the bar open while reading a guide. Text selection and scrolling within guides do not trigger page swipes.
- Authenticated Claude Code hook helper, encrypted local credentials, Content Security Policy, Windows CI, and installer SHA-256 checksums.

### Install

Download **FloatingBar_1.0.0_x64-setup.exe** or **FloatingBar_1.0.0_x64_en-US.msi** and verify it against **SHA256SUMS.txt**. Quit FloatingBar from its tray menu before installing an update.

Open **Agenda → Panduan koneksi Google Calendar**, the Discord panel, or **AI → ChatGPT / Codex** for connection instructions. Windows 11 x64 is the validated platform.

### Notes

- This is a stable release. The interface and connection guides are in Indonesian. Installers are not code-signed; Windows 10 compatibility is not validated.
- Google Calendar uses read-only access and still requires a user-configured Google Cloud Desktop app OAuth client. The guide explains this setup; it does not introduce a shared one-click sign-in service.
- Discord voice requires the desktop app, your own integration credentials, and available RPC access. No service credentials or personal account screenshots are bundled.
- **ChatGPT / Codex** uses Codex CLI/App Server and existing CLI sign-in. Ordinary ChatGPT history is not imported. Direct approvals cover supported requests in FloatingBar-owned sessions; external desktop detection remains experimental and off by default.
- Codex accepts text prompts; Claude retains image support. Antigravity chat and structured Codex tool forms are not included in stable support.
- The maintainer reports successful installation/update/uninstall, persistence after restart, core integrations, and recovery after network loss or sleep/resume. Device coverage is not claimed for every Windows build or display configuration.
