# FloatingBar v0.3.0

Chat with Codex and answer permission requests from FloatingBar, alongside the existing Claude panel, Discord voice controls, daily planning, music, and notifications.

### Highlights

- New **ChatGPT / Codex** selector on the AI page, using the official Codex App Server and your existing Codex CLI sign-in.
- List conversations with pagination, read recent history, send text prompts, receive streamed replies, and interrupt FloatingBar-owned turns.
- Sending from an existing conversation creates a fork to preserve the original session.
- Answer supported permission requests with **Allow once / Deny**. Handles both decline and cancel-only requests without granting persistent or session-wide rules.
- Permission cards identify their source and queue requests from multiple windows. Experimental desktop adapters can open recognized ChatGPT / Codex and Antigravity prompts.
- Revalidates desktop prompt identities before answering, rejects stale requests, and shows delivery errors.
- Scrollable permission details, updated fictional screenshots, and repeatable local protocol/history tests.

### Install

Download **FloatingBar_0.3.0_x64-setup.exe** or **FloatingBar_0.3.0_x64_en-US.msi** below. Quit any running FloatingBar instance before installing on Windows 10/11.

### Notes

- This is a pre-release. The interface is in Indonesian; installers are not code-signed.
- The **ChatGPT / Codex** label covers the OpenAI host detected on Windows. Chat and approval support use Codex CLI/App Server sessions; ordinary ChatGPT chat history is not automatically imported.
- Install and sign in to Codex CLI before selecting the panel. Alternate binary locations can use FLOATINGBAR_CODEX_BIN.
- Direct approvals cover turns launched through FloatingBar. Existing desktop/CLI sessions use the separate experimental desktop detector; their pending requests are not automatically transferred to the App Server connection.
- New sessions default to read-only with on-request approval. An accepted command can still be restricted by its sandbox. Permission grants are limited to the requested action or turn, depending on request type.
- Codex currently accepts text prompts. Image attachments remain available in the Claude adapter. Structured forms and multi-choice tool interactions are not implemented.
- Antigravity chat is not implemented. Claude desktop integration still depends on its English accessibility labels; Claude Code permissions use the documented hook.
- Validation includes live Codex listing/history, text send/streaming, rejection of a real permission request, and one-time approval of a harmless output command with exit code 0. UI demos and 14 internal tests passed; native installer click-through remains a separate validation step.
