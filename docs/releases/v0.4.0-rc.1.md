# FloatingBar v0.4.0-rc.1

A security and reliability candidate for the first stable FloatingBar release, with authenticated Claude Code hooks and repeatable Windows release checks.

### Highlights

- Replace the fixed, unauthenticated Claude Code endpoint with an exec-form helper, per-run DPAPI credentials, and a random loopback port.
- Reject browser-origin requests, invalid authentication, ambiguous headers, oversized bodies, slow requests, and excess pending work. Failures return to Claude's own prompt without granting permission.
- Configure or repair the Claude Code hook from AI settings. Existing FloatingBar hooks migrate with a backup while unrelated settings are preserved.
- Restore pending permission cards after renderer reloads and keep delivery failures visible.
- Disable experimental external desktop detection by default; enable it explicitly in AI settings. Claude and FloatingBar-owned Codex sessions remain available.
- Add a release Content Security Policy, pinned Windows CI, 36 offline regression tests, artifact credential checks, and installer SHA-256 checksums.
- Add an isolated native test profile without using personal accounts or conversations.

### Install

Download **FloatingBar_0.4.0-rc.1_x64-setup.exe** or **FloatingBar_0.4.0-rc.1_x64_en-US.msi** and verify it against **SHA256SUMS.txt**. Quit running FloatingBar before installing. Windows 11 x64 is the tested platform; Windows 10 compatibility is unverified for this candidate.

### Notes

- This is a pre-release, not v1.0. Installers are not code-signed. Clean-machine installation, upgrade/uninstall, reboot/sleep, and broader display testing remain release gates.
- Claude Code exec-form hooks require version 2.1.207 or later; tested with 2.1.312. Open **AI → Pengaturan AI** to set up the helper, then start a new Claude Code session.
- The UI remains Indonesian. **ChatGPT / Codex** uses Codex CLI/App Server and existing CLI sign-in; ordinary ChatGPT history is not imported. Existing conversations are forked on first send.
- Codex accepts text; Claude retains image support. Direct approvals cover supported requests from FloatingBar-owned sessions. External OpenAI and Antigravity detection only offers opening the source app; Antigravity chat is not implemented.
- No service credentials are bundled. The maintainer has confirmed rotation of the historically exposed Discord secret. Configure your own integration credentials locally.
